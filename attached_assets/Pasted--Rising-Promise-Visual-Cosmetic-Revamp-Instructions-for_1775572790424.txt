# Rising Promise — Visual & Cosmetic Revamp

## Instructions for Replit AI

You are doing a **cosmetic-only revamp** of the Rising Promise React site.

**DO NOT change:**

- Any copy or text content
- Any section structure or order
- Any feature flags or functionality
- Any form fields or button actions
- The shadcn/ui component library usage

**ONLY change:**

- Visual design (colors, typography, spacing, depth)
- Animations and motion
- Background treatments and textures
- Button styling (keep actions the same)
- Card and section styling
- Overall visual hierarchy and polish

-----

## DESIGN DIRECTION

**Mood:** Powerful + Credible. Premium modern nonprofit. Bold but never loud. The site should feel like serious people doing serious work — with a human heartbeat underneath.

**Reference feeling:** Think ACLU meets Apple. Institutional credibility with genuine warmth. A funder should feel trust immediately. A participant should feel seen.

**One rule above all:** Every design decision should make the mission feel more real — not more corporate, not more decorative.

-----

## TYPOGRAPHY

Replace current fonts with this pairing:

- **Display / Headings:** `DM Serif Display` (Google Fonts) — elegant, weighty, authoritative. Use for all h1, h2 headlines.
- **Body / UI:** `DM Sans` (Google Fonts) — clean, modern, highly legible. Use for paragraphs, labels, buttons, nav.

**Type scale:**

- Hero h1: 4.5rem / 700 weight / tight letter-spacing (-0.02em)
- Section h2: 2.75rem / DM Serif Display
- Card titles: 1.25rem / DM Sans 600
- Body: 1rem / DM Sans 400 / line-height 1.7
- Small labels / sub-labels: 0.75rem / DM Sans 500 / uppercase / letter-spacing 0.08em

-----

## ANIMATION SPECS

Stack: Framer Motion (already installed). Keep all animations subtle and purposeful.

### Rules:

- Use `whileInView` with `viewport={{ once: true }}` — animate once, not every scroll
- Easing: `[0.25, 0.1, 0.25, 1]` cubic bezier throughout
- NO scale transforms on hover (except very subtle 1.02 max on cards)
- NO glowing effects
- NO color-changing animations
- Respect `prefers-reduced-motion` — wrap all motion in a check

### Specific animations:

**Hero (on page load):**

```
- Amber label: fade in, duration 0.4s, delay 0s
- Headline: fade in + translateY(20px → 0), duration 0.7s, delay 0.15s
- Subheadline: fade in, duration 0.6s, delay 0.35s
- Buttons: fade in, duration 0.5s, delay 0.5s
```

**Section headings (on scroll into view):**

```
- Fade in + translateY(16px → 0), duration 0.6s
```

**Cards (staggered on scroll into view):**

```
- Each card: fade in + translateY(24px → 0)
- Stagger delay: 0.1s between cards
- Duration: 0.5s per card
```

**Stat numbers:**

```
- Count up from 0 to target value when section enters viewport
- Duration: 1.5s, easeOut
```

**Team cards:**

```
- Same as program cards — staggered fade + slight rise
```

**NO animations on:**

- Navigation
- Footer
- Buttons (hover states are CSS only)
- Form inputs
