# Rising Promise Website - Replit AI Prompt

## Project Overview

Create a modern, mobile-optimized multi-page nonprofit website for “Rising Promise” with an easy content management system.

-----

## PURPOSE

Rising Promise is a mission-driven nonprofit empowering vulnerable populations through workforce training, wraparound support, and community investment. We serve individuals experiencing homelessness, women rebuilding their lives, veterans, foster youth aging out of care, and families seeking stability.

-----

## SITE STRUCTURE

Main site (index.html) + separate pages for Raffle and Programs that can be activated later

-----

## CRITICAL REQUIREMENT - EASY EDITING

Create a simple config.js file that contains ALL editable content (text, links, images) so I can update the site without touching HTML/CSS. Include clear comments explaining what each section does.

Example structure:

```javascript

  hero: {
    headline: "Everyone Deserves a Fighting Chance",
    subheadline: "We believe potential isn't determined...",
    buttonText: "Learn Our Story",
    backgroundImage: "images/hero.jpg"
  },
  // etc.
}
```

- Clean, emotional, trustworthy nonprofit aesthetic
- Mission-first storytelling approach (not corporate)
- Colors: Deep navy (#0D1B2A), vibrant sky blue (#1B9CE5), warm white (#FFFFFF), accent gold (#F4A300)
- Typography: Modern sans-serif for headers, readable sans-serif for body text
- Powerful imagery (hope, forward movement, NOT sad/desperate)
- Clear, action-oriented CTA buttons throughout
- Smooth scrolling navigation with sticky header
- Mobile-first responsive design


### EDITING SYSTEM

- config.js contains ALL text, links, images in clearly labeled objects
- Include toggle flags for showing/hiding sections:

```javascript
const siteConfig = {
  features: {
    raffleActive: false,
    programsActive: false,
    cnaApplicationOpen: false,
    itApplicationOpen: false
  }
}
```

- Clear comments explaining how to edit each section
