## ANIMATION REQUIREMENTS (CSS Only - Performance Optimized)

Add subtle, meaningful animations that reinforce the mission of “rising” and forward movement:

### 1. Hero Section Animation

- Fade in from opacity 0 to 1 over 1 second on page load
- Elements slide up 20px during fade-in
- Use CSS @keyframes named “fadeInUp”
- Apply to hero headline, subheadline, and CTA buttons

### 2. Scroll-Triggered Section Reveals

- Apply to: section headings, “What We Do” cards, “Team” cards, “Impact” stats
- Use Intersection Observer API to add “visible” class when element is 15% into viewport
- Fade from opacity 0 to 1 over 0.8 seconds
- Slight upward movement (15px) during fade
- Include fallback for browsers without Intersection Observer support

### 3. Button Hover Effects

- Scale to 1.05x on hover
- Add subtle box-shadow glow (0 4px 20px rgba(27, 156, 229, 0.4))
- Smooth color transition on hover (sky blue to slightly darker)
- Transition duration: 0.3s
- Use CSS transform for performance (not top/left positioning)

### 4. Card Stagger Animation

- When card containers become visible, stagger child cards by 0.15s each
- Maximum 4 cards staggered per section
- Use CSS animation-delay with nth-child selectors
- Cards in “What We Do”, “Team”, and “Programs” sections

### 5. Accessibility & Performance

- Respect prefers-reduced-motion media query (disable animations if set)
- Use only transform and opacity for animations (GPU accelerated)
- No JavaScript animation libraries needed
- Smooth 60fps performance on mobile devices

### 6. Implementation Notes

- Include clear CSS comments showing how to disable specific animations
- Add “no-animations” class option to body tag for easy global disable
- Ensure animations don’t block or delay content rendering
- Subtle and purposeful, never flashy or distracting

**animations.js should include:**

```javascript
// Intersection Observer for scroll animations
document.addEventListener('DOMContentLoaded', function() {
  // Check if animations are enabled in config
  if (!siteConfig.features.animationsEnabled) {
    document.body.classList.add('no-animations');
    return;
  }

  // Intersection Observer options
  const observerOptions = {
    threshold: 0.15,
    rootMargin: '0px 0px -50px 0px'
  };

  // Callback function
  const observerCallback = (entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        entry.target.classList.add('visible');
        // Optionally unobserve after animating once
        observer.unobserve(entry.target);
      }
    });
  };

  // Create observer
  const observer = new IntersectionObserver(observerCallback, observerOptions);

  // Observe all elements with fade-in class
  document.querySelectorAll('.fade-in-section, .card-container').forEach(el => {
    observer.observe(el);
  });
});

// Number counter animation for stats
function animateNumber(element, target) {
  const duration = 2000;
  const start = 0;
  const increment = target / (duration / 16);
  let current = start;

  const timer = setInterval(() => {
    current += increment;
    if (current >= target) {
      element.textContent = formatNumber(target);
      clearInterval(timer);
    } else {
      element.textContent = formatNumber(Math.floor(current));
    }
  }, 16);
}

function formatNumber(num) {
  if (num >= 1000000) {
    return '$' + (num / 1000000).toFixed(1) + 'M';
  } else if (num >= 1000) {
    return (num / 1000).toFixed(0) + 'K';
  }
  return num.toString();
}

// Trigger number animations when stats section is visible
const statsObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      document.querySelectorAll('.stat-number').forEach(stat => {
        const target = parseInt(stat.dataset.target);
        animateNumber(stat, target);
      });
      statsObserver.unobserve(entry.target);
    }
  });
}, { threshold: 0.5 });

const statsSection = document.querySelector('#impact');
if (statsSection) {
  statsObserver.observe(statsSection);
}
```

## TONE & STYLE GUIDELINES

**Voice:**

- Personal, emotional, direct (NOT corporate or institutional)
- Empowering and hopeful (NOT pitying or condescending)
- Action-oriented (NOT passive or academic)
- Conversational yet professional
- “We’re in this together” NOT “We’re helping you”

**Avoid:**

- Nonprofit clichés (“changing lives one person at a time”, “making a difference”)
- Sad, desperate, or pitying imagery/language
- Corporate jargon or overly formal language
- Passive voice
- Long, complicated sentences

**Embrace:**

- Real stories and personal quotes
- Forward-looking, aspirational language
- Clear, direct calls to action
- Authentic emotion without manipulation
- Simple, powerful statements
